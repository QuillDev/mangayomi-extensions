# Mangayomi anime extensions (Nanime fork)

Anime sources in the Mangayomi extension format, used by [Nanime](https://github.com/QuillDev/Nanime). Forked from [m2k3a/mangayomi-extensions](https://github.com/m2k3a/mangayomi-extensions) (Apache-2.0).

Changes from upstream:

- Anime only: manga and novel sources are removed.
- No NSFW sources, including general video sites with adult categories.
- Dart sources are being ported to JavaScript so apps without Mangayomi's Dart interpreter can run them.
